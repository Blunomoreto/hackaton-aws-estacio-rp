# PataSegura — Equipe 3

O PataSegura é um aplicativo web criado pelo Grupo 3 para tutores de animais, ONGs de proteção animal e moradores de São Paulo que querem ajudar pets em situação de risco. 
Nele é possível registrar e buscar pets desaparecidos, reportar avistamentos e fazer denúncias de maus-tratos de forma totalmente anônima. 
Todas as denúncias alimentam um mapa de risco que mostra, por distrito, onde os casos se concentram na cidade. 

Para usar, instale as dependências com `pip install -r requirements.txt`, rode `streamlit run app.py` e navegue pelas quatro abas no navegador.
